## 四、文档维护规则

1. **同源唯一**：一个事实只有一个权威出处。坑的详情只在坑大全；命令只在运维速查；不要两处都写全文。
2. **新文档必须登记进本索引**（§二表格 + 必要时路由表）；废弃文档移入 `docs/archive/` 并在本表标注"已废弃"。
3. **每轮开发收尾回写四处**：本文件「30 秒现状」→ `项目全景与开发史.md` 时间线 → `HANDOFF` §3/§4/§7 → 涉及的专题文档。
4. HANDOFF 是**append-only 档案**：只加新小节（4.x 顺延）、只改状态行，不重写历史小节。
