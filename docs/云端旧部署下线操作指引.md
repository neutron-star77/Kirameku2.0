## 一、阿里云宝塔旧站 boke.hiromu.top（程度最高，含公网服务器）

> 这是阿里云 ECS 上的宝塔面板 + 站点，会持续产生服务器/带宽计费，**优先级最高**。

### 1.1 登录
- 浏览器打开宝塔面板：`http://<ECS公网IP>:8888`（或你记忆的入口），用面板账号密码登录。
- 若忘密码：SSH 到 ECS 执行 `bt` 选择重置面板密码；或登录阿里云控制台 → 轻量应用服务器/ECS → 重置远程密码。

### 1.2 先停服务（网站不再对外）
- 宝塔 →「网站」→ 找到站点（如 `boke.hiromu.top`）→ 右侧「停止」。
- 或「站点设置 → SSL」确认无强制跳转残留。

### 1.3 校验：旧域名确实访问不了
- 无痕访问 `http://boke.hiromu.top` → 应显示连接失败 / 站点已停。

### 1.4 需要时导出数据留档（可选）
- 宝塔 →「网站」→「备份」→ 备份整站；数据库 →「备份」→ 备份库 → 下载到本地 `F:\AI\projects\Kirameku2.0\backups\旧站_阿里云\`。

### 1.5 释放服务器（彻底下线，停止计费）
两种做法任选其一：
- **只关停（保留数据/可救回）**：阿里云控制台 → 对应服务器 →「停止」实例（后续按量费用停止，但磁盘/快照仍计费）。
- **释放实例（彻底删除，防泄门口径）**：控制台 →「实例」→「释放」，按提示强制/正常释放。**如有快照/镜像也一并删除**，否则仍计费。
- 若该服务器上还跑其他服务，请**只停站点、勿释放服务器**。

### 1.6 域名与 DNS（重要）
- `boke.hiromu.top` 解析在阿里云 DNS（云解析）。释放服务器后，删除该解析记录或在 DNS 停止，防止指向已释放的 IP。
- 若 `hiromu.top` 还有其他用途，只删 `boke` 子记录。

## 二、Cloudflare Pages 旧前端 neutronstar-front.pages.dev

> 旧前端曾用 CF Pages（因 Next16 与 CF 适配器不兼容已迁回 NAS 容器）。Pages 免费额度，但挂着的 `*.pages.dev` 域名易被漏网访问到，建议删除。

### 2.1 登录 Cloudflare
- `dash.cloudflare.com` → 用部署账号登录（账户 ID 参考 d4add8ad…，与隧道同账户）→ 左侧「Workers 和 Pages」。

### 2.2 定位旧项目
- 「Workers 和 Pages」→「Pages」标签页 → 找到 `neutronstar-front`（或带 `-front`/`-pages` 的项目）。
- 查看其自定义域：若之前绑了 `neutronstar.fun` / `www`，**先确认这些域已在新隧道接管**（即 CF DNS 中该域记录当前由新 tunnel 托管），再删 Pages 里的绑定。

### 2.3 解除自定义域绑定（若存在）
- 进入项目 →「自定义域」→ 删除 `neutronstar.fun`、`www.neutronstar.fun` 等的 Pages 绑定（新站已通过隧道用同一批域的 DNS 记录，此步把 Pages 从这些域摘除，避免冲突）。

### 2.4 删除项目
- 项目详情右上角「… → 删除项目」，确认输入项目名。

### 2.5 校验
- 无痕访问 `https://neutronstar-front.pages.dev` → 应 404 / 项目不存在。
- `https://neutronstar.fun` 仍正常 → 隧道接管成功。

> 提示：若只想让旧 `pages.dev` 失效而不删项目，也可在「设置 → 域名」删除默认 `pages.dev` 子域，页面即不可访问。

## 三、Vercel 旧页面（www 已改旁路，残存项目/部署）

> 按此前记录，`www.neutronstar.fun` 已改指向新隧道，Vercel 项目已不对外服务主站，属于"残存项目"。可胖删除或删除。

### 3.1 登录 Vercel
- `vercel.com` → 用原绑定的 GitHub 账号登录（项目应是 Xinghongia 或 neutron-star77 名下）。

### 3.2 定位项目
- 「Projects」→ 找到旧前端项目（名称含 `neutronstar` / `kirameku` / `blogs` 等）。
- 确认其「Domains」里没有仍生效的 `neutronstar.fun` / `www`（应当已移除）。

### 3.3 彻底下线
- 进入项目 →「Settings → Danger Zone」→「Delete Project」，输入项目名确认。
- **分支预览与阿里云无关**：Vercel 的 Preview Deployments URL（`*.vercel.app`）会随项目删除一并失效。

### 3.4 校验
- 无痕访问旧 `*.vercel.app` 链接 → 404 项目不存在。
- `https://neutronstar.fun`、`https://www.neutronstar.fun` 正常。
